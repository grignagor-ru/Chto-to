# Telegram мини-приложение для анонимного общения

Готовый MVP-бот для Telegram (запуск в Google Colab):
- анонимные посты,
- приватный диалог с автором поста,
- простая сегментация по возрастным группам и интересам.

## Что умеет

1. **Профиль пользователя**: возрастная группа и интересы.
2. **Анонимные посты**: публикуются с рандомным alias (`Anon-XXXXX`).
3. **Лента постов**: пользователь видит подборку (упрощенный фильтр по своему профилю).
4. **Приватные диалоги**: читатель может написать автору поста, не раскрывая данные в ленте.

## Как пользоваться ботом

1. Открой своего бота в Telegram.
2. Нажми `/start`.
3. Настрой профиль (`Возраст; интересы`) через кнопку или команду `/profile`.
4. Создай пост через `/newpost`.
5. Посмотри ленту `/feed`.
6. Нажми «Написать автору» под любым постом — откроется приватный анонимный диалог.
7. Для ответа используй формат:

```text
/reply <dialog_id> <текст>
```

## Важные замечания

- Это **MVP-прототип** для старта.
- Хранилище — `SQLite` (файл `anon_chat.db`), для продакшена лучше Postgres.
- Нет модерации контента/жалоб — рекомендуется добавить.
- Нет полноценной web mini app части (frontend), это бот-ядро с логикой анонимных постов и приватного общения.
